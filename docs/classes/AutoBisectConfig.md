# AutoBisectConfig

`AutoBisectConfig` (`src/main/java/com/xsasakihaise/hellascontrol/bisect/AutoBisectConfig.java`) defines JSON-configured settings for the auto-bisect tool.

## Responsibilities
- Loads `config/hellas/bisect.json` when present.
- Stores launch command, mod directories, baseline list, and copy directories.
